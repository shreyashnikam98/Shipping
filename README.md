# Vivian Conveyors – Ship Loading Website

A responsive 12-page static website built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or run a local static server from this directory (for example `python -m http.server 8000`) and visit `http://localhost:8000`.

## Pages
1. Home (`index.html`)
2. About Us (`about.html`)
3. Products (`products.html`)
4. Mobile Ship Loader (`mobile-ship-loader.html`)
5. Telescopic Ship Loader (`telescopic-ship-loader.html`)
6. Mobile Hopper (`mobile-hopper.html`)
7. Belt Conveyor Systems (`belt-conveyors.html`)
8. Ship Loading Solutions (`ship-loading-solutions.html`)
9. Materials Handled (`materials.html`)
10. Industries & Applications (`industries.html`)
11. Gallery (`gallery.html`)
12. Contact (`contact.html`)

## Before publishing
- Verify company contact details and replace placeholders with approved information.
- The contact form is frontend-only and does not send or store submissions. Connect a secure backend or email service before production use.
- Confirm all product descriptions and technical claims with the company. No unverified capacities, certifications or performance figures are stated.
- Google Fonts are loaded from the internet; the site otherwise uses local assets.
